# docs/inbox/ — otriagerade fynd

Nattliga automatiserade routines skriver hit. De skriver **aldrig** direkt i
`docs/PLAN.md` eller `docs/gtm/*` — bara i den här mappen.

## Format

Ett fynd per fil: `docs/inbox/YYYY-MM-DD-<ämne>.md`

## Triage

Erik triagerar fynden. Godkända fynd flyttas manuellt (eller via Claude Code)
in i rätt kanoniskt dokument. Filer i denna mapp som är äldre än 30 dagar
utan åtgärd raderas.
