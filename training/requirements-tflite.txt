# ONNX -> TFLite conversion for the native spike (training/export_tflite.py). Python 3.11, Windows.
# Own venv: onnx2tf pins a TensorFlow/onnx stack that clashes with requirements.txt.
#
#   py -3.11 -m venv training\.venv-tflite
#   training\.venv-tflite\Scripts\python.exe -m pip install --no-deps onnx2tf==1.29.24
#   training\.venv-tflite\Scripts\python.exe -m pip install -r training\requirements-tflite.txt
#
# onnx2tf is installed with --no-deps because its pins include ai-edge-litert==2.1.0, which has
# no Windows wheel. export_tflite.py points that module name at TensorFlow's own TFLite
# interpreter instead. Everything below is onnx2tf 1.29.24's own pin list minus that one.
